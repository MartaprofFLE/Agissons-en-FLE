1. Le présent de l'indicatif

Théorie

Le présent sert à parler d'une action qui se passe maintenant, d'une habitude ou d'une vérité générale.

Verbes en -ER (1er groupe) — ex. PARLER :

je parletu parlesil/elle parle
nous parlonsvous parlezils/elles parlent

Verbes en -IR (2e groupe) — ex. FINIR :

je finistu finisil finit
nous finissonsvous finissezils finissent

Verbes irréguliers très fréquents :

ÊTREAVOIRALLERFAIRE
je/j'suisaivaisfais
tuesasvasfais
il/elleestavafait
noussommesavonsallonsfaisons
vousêtesavezallezfaites
ils/ellessontontvontfont

2. L'imparfait

Théorie

L'imparfait exprime une habitude dans le passé, une description ou une action qui dure dans le passé.

Verbe régulier — ex. PARLER :

je parlaistu parlaisil/elle parlait
nous parlionsvous parliezils/elles parlaient

Formation : on prend le radical du verbe au présent avec nous (nous parl-ons) et on ajoute les terminaisons -ais, -ais, -ait, -ions, -iez, -aient — pour tous les verbes.

Seule exception : ÊTRE

j'étaistu étaisil/elle était
nous étionsvous étiezils/elles étaient

Mots qui annoncent l'imparfait : quand j'étais petit, tous les jours, autrefois, à cette époque, souvent...

3. Le passé composé

Théorie

Le passé composé exprime une action ponctuelle et finie dans le passé.

Verbe régulier avec AVOIR — ex. PARLER :

j'ai parlétu as parléil/elle a parlé
nous avons parlévous avez parléils/elles ont parlé

Verbe avec ÊTRE — ex. ALLER :

je suis allé(e)tu es allé(e)il est allé / elle est allée
nous sommes allé(e)svous êtes allé(e)sils sont allés / elles sont allées

Formation : auxiliaire (AVOIR ou ÊTRE) au présent + participe passé du verbe.

Participe passé :

Verbes en -ER→ -éparler → parlé
Verbes en -IR (2e gr.)→ -ifinir → fini
Irréguliersavoir → eu · être → été · faire → fait · aller → allé · venir → venu · voir → vu · prendre → pris

Verbes avec ÊTRE (mouvement / changement d'état) : aller, venir, partir, arriver, entrer, sortir, monter, descendre, naître, mourir, rester, devenir, tomber, retourner, passer.

Avec être, le participe passé s'accorde avec le sujet : Elle est allée, ils sont partis. Avec avoir, il ne s'accorde pas avec le sujet.

4. Le futur proche

Théorie

Le futur proche exprime une action qui va se passer bientôt, dans un futur immédiat.

Formation : verbe ALLER au présent + infinitif du verbe.

je vais parlertu vas parleril/elle va parler
nous allons parlervous allez parlerils/elles vont parler

À la forme négative : on met ne ... pas autour du verbe ALLER. Ex. : Je ne vais pas sortir.

Mots qui annoncent le futur proche : tout de suite, bientôt, dans un moment, ce soir, demain, la semaine prochaine...

Attention : on n'utilise pas l'infinitif de « aller » : on dit je vais y aller et non « je vais aller » dans la langue courante.

Écris « aller » au présent + l'infinitif du verbe (sans le pronom). Ex. : « vais parler ».
Exercice 3 — Petite rédaction

5. Le futur simple

Théorie

Le futur simple exprime une action qui se passera plus tard.

Verbe régulier en -ER — ex. PARLER :

je parleraitu parlerasil/elle parlera
nous parleronsvous parlerezils/elles parleront

Verbe régulier en -IR — ex. FINIR :

je finiraitu finirasil/elle finira
nous finironsvous finirezils/elles finiront

Formation : infinitif du verbe + terminaisons -ai, -as, -a, -ons, -ez, -ont (qui ressemblent au verbe avoir au présent).

Verbes irréguliers (radical spécial) :

VerbeRadicalExemple
êtreser-je serai
avoiraur-j'aurai
allerir-j'irai
fairefer-je ferai
venirviendr-je viendrai
voirverr-je verrai

Mots qui annoncent le futur : demain, la semaine prochaine, dans deux ans, plus tard...

Écris la forme correcte (sans le pronom).
